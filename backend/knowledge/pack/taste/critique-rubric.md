# Critique rubric (0–80)

Use this on your own output before delivering, and on a model's output when reviewing.

## Score eight categories, 0–10 each
| # | Category | What earns a 10 |
|---|---|---|
| 1 | Hierarchy | one entry point, ≥2.5× type ratio, rhythm between levels |
| 2 | Space & rhythm | 4pt grid, inside > outside padding, ≥40% rest space, one big-air moment |
| 3 | Colour | one accent ≤2 uses, neutrals 70–90%, computed contrast, no banned hue |
| 4 | Type | display voice with personality, negative tracking on display, one serif voice |
| 5 | Components | states complete, one icon family, controls feel physical (springs) |
| 6 | Flow & UX | one decision per screen, primary action in the thumb zone, laws of UX honoured |
| 7 | States | loading / empty / error / populated / edge all designed |
| 8 | Originality | could not be mistaken for another product; one memorable thing |

**Verdict:** 72+ SHIP · 56–71 FIX-FIRST · < 56 REGENERATE.

## The genericness test (run it out loud)
> "Cover the logo. What product is this, and who is it for?"

If you cannot answer in one sentence, category 8 is ≤3 no matter how clean the screen is.

## Fixing, not vibing
Never send "make it better". Send one named move with a number:

| Move | What it changes |
|---|---|
| **distill** | remove one section and one decoration; raise whitespace |
| **bolder** | display +1 step, weight contrast up, accent committed once |
| **quieter** | accent uses 2→1, saturation −10%, shadows −1 layer |
| **typeset** | fix ratio to ≥2.5×, tracking, line-height, one serif voice |
| **layout** | fix the grid, inside/outside padding, one grid break |
| **animate** | apply exactly the two allowed effects with token timings |
| **harden** | stress with the edge matrix; fix what breaks |
| **recolour** | one accent, neutrals 70–90%, contrast computed |

Two moves maximum per round. Three means the hand was wrong — re-deal.

## Report format
```
SCORE: 64/80
WEAKEST: 3 (colour) and 8 (originality)
TOP 3 FIXES:
  1. accent uses 4 → 2 (drop the gradient card and the icon tint)
  2. display 34/15 → 42/15 (ratio 2.27 → 2.8)
  3. add one memorable element: the mascot reacts to the generated design
SLOP FLAGS: coloured left-border card (#5), invented metric "10× faster" (#6)
VERDICT: FIX-FIRST
```
