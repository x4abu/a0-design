# The taste tests

Rules stop slop. These tests are what stop *competent but forgettable*. Run every one
before you ship a screen; a single "no" means revise, not "note it for later".

## 1. Accent removal test
Remove the accent colour in your head. Does the hierarchy still work?
- **Pass:** the eye still lands on the headline, then the primary action.
- **Fail:** everything goes flat — meaning the layout is doing no work and the colour was
  carrying it. Fix the type scale and spacing, not the palette.

## 2. Blind identity test
Cover the logo and the product name. Could a stranger name the product from the screen?
- **Pass:** the subject matter is visible in the content, the type and the imagery.
- **Fail:** any of three apps could be the answer. Change one **structural** thing — the
  grid, the entry point, the type pairing — not the colour.

## 3. Loudness count
Count the loud things: accent surfaces + gradients + animation + oversized type + imagery.
- **Pass:** ≤ 2.
- **Fail:** 3+. Cut until two remain. The cut one is usually the gradient.

## 4. One memorable thing
Name the one thing a person would describe to a friend tomorrow.
- **Pass:** you can name it in one sentence ("the mascot blinks when it's thinking").
- **Fail:** you cannot name it. There isn't one. Add exactly one, then stop.

## 5. Squint test
Blur your eyes (or zoom to 40%). Does the eye land on the same element as at 100%?
- **Pass:** same order. Hierarchy is structural.
- **Fail:** the order changes — hierarchy is being carried by detail (hairlines, small
  icons, colour), which disappears at a glance.

## 6. Type test
- Display ÷ body ≥ 2.5×?
- Negative tracking on display, zero on body?
- One serif voice, or one grotesk voice — not three weights of the same sans pretending to
  be a hierarchy?
- Is the display face actually doing something (a shape, a contrast, a personality)?
- **Fail:** if the answer to the last one is "it's just Inter bold", the screen has no voice.

## 7. Motion justification
For every animation, answer: **what moved, and what did the user learn?**
- **Pass:** the transition explained where the content came from, or confirmed an action
  the user just took.
- **Fail:** "it looked nice." Delete it. Ambient loops: maximum one, and it must be the
  mascot or nothing.

## 8. Restraint audit (added in v2)
Open the screen and count: blurred surfaces, gradients, springs on non-touch elements,
shadows, borders, decorative icons.
- **Pass:** ≤ 1 blurred surface, ≤ 1 gradient, ≤ 3 shadowed surfaces.
- **Fail:** the screen is decorated rather than designed. Remove one layer entirely.

## How to use these
Run 1–5 on a static screenshot (they are compositional). Run 6–8 on the source (they are
token-level). If a model produced the screen, paste the failed test back verbatim —
"test 3 fails: three loud things, cut the gradient" — rather than "make it cleaner".
