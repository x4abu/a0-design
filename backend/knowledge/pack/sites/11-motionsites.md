# MotionSites — AI website prompts and motion inspiration

**What it is.** A library of AI-generated website prompts paired with design inspiration,
positioned as "develop your AI design skills that stand out". The value is the *prompt
shape*: briefs that specify motion, layout and mood precisely enough that a model produces
something specific instead of the average.

**The prompt pattern that works (reconstructed and improved):**
```
Build <surface> for <subject>. Mood: <3 adjectives from the palette doc>.
Layout: <one structural idea>. Type: <display family> at <size>, <body family> at <size>.
Palette: <bg hex> canvas, <ink hex> text, one accent <hex>.
Motion: <2 named effects> — <duration + easing>. Everything else static.
Constraints: no purple/blue/neon, no emoji icons, no placeholder copy, one CTA.
Deliver: <platform output contract>.
```

**Why this beats "make it beautiful".** Every axis is pinned: surface, mood, one layout
idea, two type sizes, three hexes, two motions, and an explicit ban list. The model has no
room to reach for the default.
