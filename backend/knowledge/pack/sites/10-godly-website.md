# Godly.website — astronomically good web design

**What it is.** A long-running, tightly curated gallery of the best web design on the
internet — heavy on 3D, WebGL, kinetic type and editorial layouts. (It now resolves to
Recent's design feed, so the same discipline applies: extract decisions, not screenshots.)

**What to take.** The site's own bar is "would a studio put this in their portfolio?".
Use it to calibrate ambition, then translate the ambition into what a phone can do:
- WebGL/3D hero → a single gradient-lit surface, a soft shadow and a scroll-linked
  transform. Never fake 3D badly; do less, better.
- Kinetic type → one headline that animates once on load, not type that moves forever.
- Custom cursor / hover theatre → long-press and haptic feedback on mobile.

**Rule of thumb.** Everything on Godly is doing *one* thing extremely well and keeping the
rest quiet. Copy that ratio, not the effects.
